# حاسِب

منصة حاسبات عربية: الزائر يملأ جملة، والأرقام نفسها هي الحقول، والنتيجة تظهر فوراً مع طريقة حسابها.

- **8 حاسبات:** نهاية الخدمة (الإمارات)، الضريبة، القسط الشهري، النسبة المئوية، الخصم، العمر، مؤشر كتلة الجسم، الزكاة.
- **الصفحات:** الرئيسية، 3 صفحات تصنيف، من نحن، الخصوصية، الشروط، اتصل بنا، و404.
- **التقنيات:** Astro 7 (موقع ثابت مولّد مسبقاً) + TypeScript + Vitest، بدون إطار واجهة وبدون قاعدة بيانات.

## التشغيل محلياً

يحتاج Node.js 22 أو أحدث.

```bash
npm install
cp .env.example .env      # ثم عدّل القيم
npm run dev               # http://localhost:4321
```

| الأمر | ماذا يفعل |
| --- | --- |
| `npm run dev` | خادم تطوير |
| `npm test` | اختبارات المعادلات (38 اختباراً) |
| `npm run build` | يبني الموقع في مجلد `dist/` |
| `npm run check:site` | يفحص `dist/`: العناوين، والأوصاف، وcanonical، وعنوان H1 واحد، والروابط الداخلية، وsitemap |
| `npm run verify` | الثلاثة معاً: الاختبارات، ثم البناء، ثم الفحص |
| `npm run preview` | معاينة نسخة البناء |

### اختبارات المتصفح (اختيارية)

تحتاج Python وPlaywright، ويجب أن يكون الموقع مشغّلاً.

```bash
npm run build && (cd dist && python3 -m http.server 4321) &
python3 scripts/interaction_test.py   # 20 اختبار تفاعل
python3 scripts/shots.py ./shots      # لقطات للجوال والكمبيوتر في الوضعين، وفحص أخطاء الكونسول والتمرير الأفقي
```

  lib/format.ts    سياسة واحدة لتنسيق الأرقام (أرقام 123 وفواصل الآلاف)

  config/site.ts   كل الإعدادات من متغيرات البيئة
  components/      الجملة (NumIn, DateIn, Pills)، بطاقة النتيجة، الإعلان، الروابط ذات الصلة
  layouts/         Base (رأس الصفحة وSEO والهيدر والفوتر)، CalcLayout (قالب صفحة الحاسبة)

كل حاسبة لها صفحة بتركيب مختلف: شرائح الاستحقاق لنهاية الخدمة، وجدول الأصل والفائدة للقرض، ومقياس BMI، وثلاثة أسئلة منفصلة للنسبة، وغيرها.

## الإعدادات

كل الإعدادات في `.env`، وتفاصيلها في `.env.example`.

| المتغير | مطلوب؟ | الغرض |
| --- | --- | --- |
| `PUBLIC_SITE_URL` | **نعم قبل النشر** | النطاق النهائي. بدونه تستخدم روابط canonical وsitemap نطاقاً مؤقتاً (example.com) ويظهر تحذير في البناء |
| `PUBLIC_CONTACT_EMAIL` | يُفضّل | بريد يظهر في صفحة اتصل بنا وصفحة الخصوصية |
| `PUBLIC_CONTACT_FORM_ENDPOINT` | اختياري | رابط استقبال النموذج، مثل Formspree. بدونه يظهر البريد فقط |
| `PUBLIC_ADS_ENABLED` / `PUBLIC_ADSENSE_CLIENT_ID` / `PUBLIC_ADSENSE_SLOT_AFTER_CALC` | بعد قبول AdSense | الإعلانات |
| `PUBLIC_GSC_VERIFICATION` | اختياري | التحقق من Search Console بوسم meta |
| `PUBLIC_GA4_ID` | اختياري | محجوز لـ Google Analytics 4. **لم يُدمج كود التتبع بعد عمداً**، راجع قسم الخصوصية |

تاريخ آخر مراجعة للمعادلات موجود في `SITE.lastReviewed` داخل `src/config/site.ts`. حدّثه فقط عندما تراجع المصادر فعلاً.

## النشر

الموقع ثابت بالكامل: ارفع محتوى `dist/` على أي استضافة.

**Netlify (الأسهل):** اربط المستودع، وإعدادات البناء جاهزة في `netlify.toml`، وأضف متغيرات البيئة من Site settings ← Environment variables. أو ابنِ محلياً واسحب مجلد `dist/` إلى app.netlify.com/drop.

**Cloudflare Pages:**
- أمر البناء: `npm run build`
- مجلد النشر: `dist`
- إصدار Node: 22
- أضف المتغيرات في إعدادات المشروع.

**Hostinger أو أي استضافة Apache:** شغّل `npm run build` على جهازك بعد ضبط `.env`، ثم ارفع **محتوى** `dist/` (وليس المجلد نفسه) إلى `public_html`. ملف `.htaccess` مضمّن، ويضبط صفحة 404 والتخزين المؤقت والضغط.

الملف `public/_headers` يضيف رؤوس أمان على Netlify وCloudflare. لم نضع سياسة CSP صارمة، لأن تفعيل AdSense يحتاج السماح بنطاقات Google الإعلانية. إذا أضفتها، فاختبر الإعلانات بعدها.

## بعد النشر: Search Console

1. أضف النطاق في Google Search Console، وتحقق منه بسجل DNS أو بوسم `PUBLIC_GSC_VERIFICATION`.
2. أرسل `https://نطاقك/sitemap.xml`.
3. راقب تقارير الفهرسة وCore Web Vitals، وهذه هي البيانات الميدانية الحقيقية.

## تفعيل AdSense

الإعلانات مجهزة لكنها **معطلة**: لا يُحمَّل أي كود إعلاني، ولا تظهر مساحة فارغة للزائر. في وضع التطوير فقط تظهر مساحة منقطة مكتوب عليها «غير مفعّل».

1. انشر الموقع على نطاقك أولاً، مع محتوى كامل وصفحات قانونية، وكلها جاهزة.
2. قدّم على AdSense. الموافقة قرار Google ولا يضمنها الكود.
3. بعد القبول، أنشئ وحدة إعلانية متجاوبة، وضع في `.env`:
   ```
   PUBLIC_ADS_ENABLED=true
   PUBLIC_ADSENSE_CLIENT_ID=ca-pub-XXXXXXXXXXXXXXXX
   PUBLIC_ADSENSE_SLOT_AFTER_CALC=XXXXXXXXXX
   ```
4. أعد البناء والنشر. سيُنشأ `ads.txt` تلقائياً بمعرّفك، وتتحدث صفحة الخصوصية تلقائياً لتذكر الإعلانات.
5. الإعلان يظهر بعد الحاسبة وقبل المقال، بمساحة محجوزة 280px لمنع قفز الصفحة، وبعيداً عن الأزرار.

**زوار أوروبا وبريطانيا وسويسرا:** إذا كان لك زوار منها، تشترط Google أداة موافقة معتمدة (CMP)، مثل أداة الخصوصية والرسائل في AdSense نفسه. فعّلها من حساب AdSense قبل عرض الإعلانات هناك.

## ما تحتاجه مني لإكمال كل شي

- [ ] النطاق النهائي → `PUBLIC_SITE_URL`
- [ ] بريد تواصل حقيقي، و/أو رابط Formspree
- [ ] بعد القبول: معرّف AdSense ومعرّف الوحدة الإعلانية
- [ ] (اختياري) قرار بشأن Google Analytics. يحتاج إضافة الكود، وتحديث سياسة الخصوصية، وأداة موافقة إذا لزم

## حدود معروفة

- **نهاية الخدمة:** الأجر اليومي محسوب على أساس الأساسي ÷ 30، والقانون لا يحدد المقسوم صراحة. لا تغطي الحاسبة الدوام الجزئي، ولا المناطق الحرة ذات القوانين الخاصة، ولا القطاع الحكومي، ولا المواطنين. وكل هذا مذكور في الصفحة.
- **القرض:** الفائدة الثابتة نموذج مبسّط، ولا تُحتسب الرسوم والتأمين.
- **الزكاة:** حساب مبدئي للنقد، ويُدخل سعر الذهب يدوياً، وتفاصيل الاستثمارات والديون فقهية.
- **BMI:** للبالغين فقط.
- **المراجعة:** المعادلات روجعت مقابل المصادر المنشورة، وليست مراجعة من محامٍ أو طبيب أو مفتٍ.
